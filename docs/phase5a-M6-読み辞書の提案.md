依頼書 M6-1「読みの仕様は先に spec と一緒に提案し、実装は構造が決まってから」に従い、実装はまだ始めていない。

## 1. 現状

`Kakikudashi.convert` は、返り点で並べた漢字に、再読文字の送り仮名だけを足す。読みの情報を持つ語は `Lexicon::SAIDOKU` の 8 字だけで、助字・動詞の読みと活用はない。

## 2. 提案：別ファイル `lib/kanbun/yomi.rb`（未決事項 4 の既定案）

`Lexicon` は品詞のまま。書き下し用の読みは `Kanbun::Yomi::ENTRIES`（表層形 → エントリ）に分ける。エントリは 3 種類。

```ruby
# 1) 実字：漢字で出す。動詞・形容詞は「語幹＋活用型」を持つ
'知' => { kind: :verb, stem: 'し', conj: :godan_ra },   # 知ら・知り・知る・知れ
'学' => { kind: :verb, stem: 'まな', conj: :godan_ba }, # 学ば・学び・学ぶ・学べ
'行' => { kind: :verb, stem: 'ゆ',  conj: :godan_ka },
'来' => { kind: :verb, forms: { mizen: 'こ', renyo: 'き', shushi: 'く', rentai: 'くる', izen: 'くれ' } },  # 不規則は forms で直接持つ
'高' => { kind: :adj,  stem: 'たか', conj: :ku },        # 高く・高し・高き
'人' => { kind: :noun }                                     # 活用なし。漢字のまま

# 2) 助字・助動詞：ひらがなで出す。接続（直前の語に要求する形）と、自分の活用を持つ
'不' => { kind: :aux, connect: :mizen,  forms: { shushi: 'ず', rentai: 'ざる', izen: 'ざれ', renyo: 'ず' } },
'可' => { kind: :aux, connect: :shushi, forms: { shushi: 'べし', rentai: 'べき', izen: 'べけれ', neg: 'べから' } },
'如' => { kind: :aux, connect: :rentai, forms: { shushi: 'ごとし', rentai: 'ごとき' }, particle_before: 'が' },
'也' => { kind: :aux, forms: { shushi: 'なり' } },
'哉' => { kind: :aux, final: 'かな', question: 'や' },
'矣' => { kind: :okiji }, '焉' => { kind: :okiji }, '而' => { kind: :okiji }  # 接続の而は出さない（「て」は前の語の連用形に含める）

# 3) 代名詞・指示語・有無：漢字のまま（未決事項 1 の既定案）
'之' => { kind: :pron, particle: 'を' }, '其' => { kind: :pron, particle: 'の' },
'有' => { kind: :verb_kanji, forms: { shushi: '有り', rentai: '有る' } }, '無' => { kind: :adj_kanji, forms: { shushi: '無し', rentai: '無き' } }
```

## 3. 活用の付け方

読む順に並んだ語列を**右から左へ**処理する。各語は「後ろの語が要求する活用形」を受け取り、自分の形を決める。

- 後ろが `不`（connect: :mizen）→ 直前の動詞は未然形（知 → 知ら）。
- 後ろが `べし`・文末 → 終止形。後ろが `者`・`所`・`こと`・`が` → 連体形。後ろが `ば` → 已然形。後ろが接続の `而` → 連用形＋「て」。
- `不` 自身は、後ろが文末なら `ず`、名詞（者・所）なら `ざる`。
- 活用型は `godan_*`（五段）、`kami_ichi`（上一段）、`shimo_ni`（下二段）、`ku`／`shiku`（形容詞）の最小セットから始め、足りなければ forms で直接書く。
