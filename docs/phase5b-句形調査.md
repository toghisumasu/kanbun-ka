## 0. 先に：黙って誤るもの（止まらず、誤った書き下し・返り点を exact:true で返す）

**検査をすり抜ける理由**：Fukubun は文字列の欠落・重複・順序と、項目ごとの欠落・位置を見る。助詞（を／に）・活用形・構造の切り方・名詞述語の「なり」は見ない。辞書の読み自体（Yomi の表）が誤っていれば、そのまま exact:true になる。

### 1.1 特に確かめるよう求められた項目の結論
- **詠嘆 不亦〜乎**：通る（不亦説乎・不亦楽乎・不亦大乎・不亦喜乎）。ただし 大 は送り仮名が誤り（**黙って誤る** #20）。
- **部分否定**：不必〜・不常〜・不復〜・不尽〜・不甚〜 は通る（不尽・不甚 は読みが疑い、#21）。**未必〜は止まる**（`ParseError: HITSZU`）。必不〜 も止まる。
- **仮定**：通るのは 若〜則〜 と 則だけ（学則知）。**苟・使・如・雖・縦 は止まる**（苟は則と、使は則と、雖・縦は文頭では通らない）。
- **限定**：惟・独 は文法上は通るが読みがなく暫定。**但 は ADV として読みあり（exact）**。唯・徒 は辞書外で止まる。
- **疑問・反語の疑問詞**：誰・何為・何以・安 は通るが読みの辞書にない（暫定）。孰（孰賢）・焉・奚・胡 は止まる（孰・焉は文法、奚・胡は辞書外）。豈・寧 は文法は通るが読みなし（暫定）。乎・哉・耶 を**文末以外**に書くと、乎＋名詞 は置き字（於の別字）として通るが、乎＋動詞（学乎行）・哉の後ろに語（君学哉行）・文頭の乎・乎哉は**止まる**。耶 は辞書外で止まる（邪 は通る）。
- **抑揚**：猶（再読文字）は通る。**況 は文頭・文中とも止まる／暫定、尚 は辞書外**。
- **乎・于 を於の別字として**：山高于雲＝「山雲より高し」（動く）。人貴乎金は貴・金が辞書外で止まる。学乎人・学于人は通るが「他動詞＋於A」の曖昧で暫定（「人学」）。問礼乎老子＝「礼を老子に問ふ」（動く）。
- **動詞が辞書外**：彼虜敵・官保民・彼伐敵・我愛人 は `UnknownCharacters` で**止まる**（誤って「す」を付けることはない）。王臣其友 は 臣 を動詞に使う形で `ParseError: POSS` で止まる。
- **受身**：彼為敵所殺＝動く（彼は敵の殺す所と為る）。見逐於友＝止まる（逐が辞書外）、見殺於敵・見笑於人＝止まる（`ParseError: PREP`：見V於A の文法がない）。水清於玉＝止まる（玉が辞書外）、水清於氷＝動く（水氷より清し）。

### 1.3 乎・哉・耶 を文末以外に書いた場合
- 乎＋名詞 → 置き字（PREP）として通る（入乎深林・学乎人・問礼乎老子）。
- 乎＋動詞（学乎行）→ `ParseError: parse error on value "行"`（止まる）。文頭の乎・乎哉 → `ParseError`（止まる）。
- 哉＋語（君学哉行）→ `ParseError`（止まる）。耶 → `UnknownCharacters`（止まる）。
- 助字の順序・重複（学哉也・学也也 等）は S5 以前から `ParseError`（spec あり）。

### 2.2 活用の種類が欠けている動詞項目
- 動詞 78 項目は活用 5 形をすべて持つ（forms が 5 つでないものは 0）。ただし **型の名前は持たず**、`forms` の配列そのもの（GODAN 共有表または個別配列）で表す。型を直接参照する箇所がなく、型の取り違えは検査できない。
- **欠けのある項目：得**（forms が `["","","","る","れ"]`。未然・連用・終止が空）。「得」は終止形が出ず、書き下しが「名を得」で終わる（§0 #16）。
- **食い違い：賢・敏・説** は Lexicon では VERB、Yomi では ADJS にある（活用型は形容詞）。目的語を取る形（彼賢友）で誤る（§0 #19）。言 は NOUN と VERB の両方に載り、VERB が優先。
- **助詞の欠け**：obj が を以外の動詞は 行・入・還・帰・在・登（に）と 有（空）だけ。**及・随・施・対・照・満・重 などは に を取る動詞なのに obj が を**（§0 #7〜#13）。

### 2.3 辞書外の語が来たとき
- **語が Lexicon にない**：トークン化で `KanbunParser::UnknownCharacters`（`lib/kanbun/kanbun_parser.tab.rb` の tokenize が skipped を集め、strict なら raise）。Service が `rescue` して `status: :unparsed`・`error` つきで白文を返す。止まる。
- **Lexicon にあり Yomi の表にない語**（VERB・ADJ・ADV）：`yomi.rb:render_content` の末尾の `else raise MissingEntry, "読みの辞書にありません: …"`。Service が `rescue` して暫定出力・exact:false・理由。止まる（既定値で読みを作らない）。現状、Lexicon の VERB/VERB_I/ADJ/ADV で Yomi に読みがない字は 0 件。
- **既定値で読みを作ってしまう箇所**（黙って誤る側）：
  1. 名詞：`render_content` の `token == :NOUN` で、**読みの表を引かず**常に「表層形＋助詞」（`surf + it_part(it, dem)`）を返す。名詞の読みは検査できない。名詞述語に「なり」が付かないのもここ（§0 #4）。
  2. 活用形の既定：`dem[:form] || :shushi`（直前が要求しない形は終止形）、`FORMS.index(form) || 2`、`aux_neg` の `.fetch(form, 'ず')`、`render_hi` の `.fetch(form, '非ず')`、`render_nashi` の `.fetch(form, 'し')`。想定外の組み合わせでも終止形で出る。
  3. 助詞の既定：`VERBS` の obj が既定で を（`v` の既定引数 `obj: 'を'`）。
  4. 与A・自A・従A・文末の 与 は、字を出さず助詞として扱う（落ちを例外にしている）。文末の 与（疑問）もここに入り落ちる（§0 #3）。
