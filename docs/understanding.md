# 理解の記録（understanding）

## 2026-11-14 Phase 5a M1：不得不・不可不

- したこと：`不得不`・`不可不` を 3 字 1 トークン（DNEG_TOKU / DNEG_KA）にし、二重否定②として専用規則を追加した。
- 直した誤り：以前は `不得不知` が `不得 | 不知`（seq_neg_clause）として偶然通り、返り点 `不[レ]得不[レ]知`・読み順「得不知不」と、エラーなしで誤った結果を出していた。
- 検証：kunten_spec に 5 句を追加（先に赤を確認）。RSpec 400 件通過、Racc conflict 0（`lib/kanbun/kanbun_parser.output`）。
- 明文化した前提：
  - `.y` の正本は `script/kanbun_parser.y`。`bundle exec racc -v script/kanbun_parser.y -o lib/kanbun/kanbun_parser.tab.rb` で再生成する。`.output` は lib/kanbun 側に出る（script 側の `.output` は古い残骸で、gitignore 対象）。
  - 「不得」「不可」を 2 語で続けて読ませる文（不得 | 不行 のような読み）は、3 字トークンが最長一致で優先するため通らなくなる。
- 未了：書き下し「知らざるを得ず」「学ばざるべからず」は M6（読み辞書・活用）で出す。

## 2026-11-14 Phase 5a M2：辞書の追加（部分）

- 追加：NOUN 之・敵・衣・夢・益・客・人生、VERB 対、VERB_I 生、ADV 乃・即・遂・卒・已・漸・尽・妄・忽・蓋・具・敢・数、ADJ 新・疾・衆・寡。
- 検証：kunten_spec に 9 句（自作文）。RSpec 409 件通過。
- 判断：**文法規則と同時に入れる字は M3〜M5 に回した**（可・也・焉・被・徒・唯・其）。品詞だけ先に入れると、`我読其書` のように「其書」を名詞＋動詞と読み、エラーなしで誤った返り点を出すため（実際に再現して其を戻した）。
- 之は目的語の代名詞用法のみ（`我知之`）。`A之B` の連体は未対応で、通すと名詞の連続として誤読するため、必要になる時点で規則を足す。
- 辞書に既にあり新規不要だった字：此・彼・所・者・則・亦・猶・与・甚・少・見・事・汝・吾・子・風・山・水・得・哉。

## 2026-11-14 Phase 5a M3：文末助字と而

- したこと：文末助字 也・焉（新トークン SHI_YA / SHI_EN）と 哉・矣 を `final_particles` にまとめ、どの句にも文末で付けられるようにした。`而` の後ろに否定句（`学而不行`）を許した。
- 通る重ね：也哉・矣哉・也矣。通さない（ParseError）：哉也・也也・焉也・哉哉（spec に残した）。
- 置き字の区別（既定案。書き下しは M6 で反映）：矣・焉・而＝読まない置き字（Leaf.silent）。也・哉＝読む（也＝なり、哉＝か・かな）。焉は「ここに」と読む用法を扱わない。
- `独〜哉` の専用規則は削除した。`gentei_clause`＋文末助字の哉で同じ木になり、残すと shift/reduce が出るため。豈〜哉は従来どおり。
- 検証：spec を先に書いて赤（25 件失敗）を確認。RSpec 437 件通過、Racc conflict 0。
